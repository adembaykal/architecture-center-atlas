# Changelog

All notable changes to Architecture Atlas are documented here.

## v1.0.0 — 2026-09-06

Initial public release.

### Features

- **Visual Architecture Gallery** — browse all 118 reference architectures as cards with preview images, domain indicators, and partner tags
- **Search & Filtering** — full-text search; filter by domain, technology partner, and recently updated
- **Architecture Detail Panel** — title, description, domains, partners, tags, contributors, last update, and direct link to SAP Architecture Center
- **Fullscreen Diagram Viewer** — zoom, pan, and fit controls for architecture diagrams
- **Relationship Explorer** — visual ring layout showing related architectures; relationships derived from Architecture Center metadata (Same RA Group, Shared Domain, Shared Partner, Shared Tags); navigate history with Back button
- **Side-by-Side Comparison** — compare up to two architectures with diagrams and metadata
- **Global Deduplicated View** — flat view of all architectures, each appearing exactly once with all domain assignments visible
- **Domain Cluster View** — available when a domain filter is active

### Dataset

- 118 reference architecture documents
